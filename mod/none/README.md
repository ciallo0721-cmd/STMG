# 无美化 —— STMG 美化包

- **类型**：美化包（主题），不是 STMG 本体
- **作者**：STMG
- **说明**：引擎原生外观，不做任何修改。

## 这是什么

这是一份 STMG 的**外观定制包**。它只改界面长什么样，不含引擎、不含剧本，
也不改引擎的任何一行逻辑。装上它，换个外观；卸掉它，引擎回到原样。

## 怎么用

把这个文件夹整个丢进 STMG 的 `mod/` 目录里，然后在 `mod/active.json` 里写上
`"mod": "文件夹名"`（照抄 `none` 那份的写法就行），

或者用启动器：点「美化包」→ 在列表里选它 → 启用。

跑游戏时也能临时指定：

```bash
python start.py script.stm --mod <文件夹名>
python start.py script.stm --no-mod        # 临时不用任何美化包
```

## 里面有什么

| 文件 | 作用 |
|---|---|
| `mod.json` | 清单：包名 / 版本 / 作者 / 说明 |
| `gui.py` | 桌面端外观参数（只能写 CONFIG 字典，不能写代码） |
| `theme.css` | 网页版（发布为 HTML）的样式 |
| `theme.js` | 网页版行为，跑在受限沙箱里 |

## 想改它

- 改外观：动 `gui.py` 里的 `CONFIG`，或 `theme.css`
- 想改**引擎行为**（不是外观）：那不属于美化包，请直接改 STMG 源码
  `stmg/*.py`，然后自己 fork 一份。美化包永远只负责「好看」。

## 校验与发布

```bash
python tools/modcheck.py <文件夹名>      # 静态检查，看有没有违规
python tools/modpub.py  <文件夹名>       # 打包成「XXX_美化包」
```

美化包里出现可执行代码、可执行文件、远程请求，都会被拒绝发布。
