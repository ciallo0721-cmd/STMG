关于联网（剧本里的 R.api）：网页版没有服务器替你保管密钥， 剧本里填的 API Key 必然可见——任何人打开网页源码都读得到；跨域请求还需要 对方接口主动允许 CORS。请求超过 __STMG_API_SEC__ 秒没回来就放弃， STM.API 留空，剧情照常往下走。

关于文件（剧本里的 stm.os）：网页版的文件操作只发生在 浏览器沙箱里，碰不到你真实的磁盘。沙箱是浏览器自己的 IndexedDB， 换浏览器、换设备或者清空站点数据就没了。
